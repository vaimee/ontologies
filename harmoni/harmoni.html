Taxonomy of data sources for the HARMONI project, mapping open-access and institutional datasets, catalogues and services to use cases, hazards, publishers, data type families and access conditions.

This document is a work in progress

Introduction

"Taxonomy of data type families relevant to HARMONI project, with the open-access and institutional data sources mapped to each of the six HARMONI use cases, their publishers, thematic classification and access conditions. Supports Figure 6.1 of Deliverable D1.1 and provides the initial structure for the HARMONI Knowledge Graph developed in T1.4."@en
