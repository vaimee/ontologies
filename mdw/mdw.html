Horizontal vocabulary of the Milky Data Way: software agents that publish contracts, are deployed on resources and named graphs, and record the provenance of each run in a SPARQL event broker (SEPA).

This document is a work in progress

Introduction

"Domain independent: it describes agents, operations, channels, deployments, groundings, live and history graph bindings and derivations. The classes and observed properties a domain's agents read and write (for example soils, crops and weather of Agorà) belong to that domain's ontology and are referenced from contracts through semagent:hasType and semagent:hasValue."
